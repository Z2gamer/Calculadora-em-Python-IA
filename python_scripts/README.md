# Scripts em Python da Calculadora

Esta pasta contém 4 versões autônomas da calculadora escritas em Python 3, pensadas para o seu aprendizado progressivo.

## Como Executar

Abra o terminal nesta pasta e execute qualquer uma das versões com o Python 3:

```bash
# 1. Versão Inicial (As 4 operações básicas)
python3 01_calculadora_simples.py

# 2. Versão com Funções (def e return)
python3 02_calculadora_funcoes.py

# 3. Versão Contínua (Laço while True e tratamento de erros)
python3 03_calculadora_while.py

# 4. Versão Avançada (Raiz Quadrada, Potência, Porcentagem e Histórico)
python3 04_calculadora_avancada_historico.py
```

## O que cada script ensina:

| Arquivo | Conceitos Principais |
| :--- | :--- |
| `01_calculadora_simples.py` | `print()`, `input()`, `float()`, `if/elif/else`, divisão por zero |
| `02_calculadora_funcoes.py` | Funções com `def`, parâmetros `(a, b)` e retorno `return` |
| `03_calculadora_while.py` | Repetição contínua com `while True`, `break`, `try/except ValueError` |
| `04_calculadora_avancada_historico.py` | `math.sqrt()`, operador `**`, porcentagem, listas `historico = []` |
